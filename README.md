# Computer Components Store — Java + SQL Server (BD Edition)

Extension of the POO final project, adding a full database layer with SQL Server.

Built for the Databases course at PUCMM, this version replaces in-memory storage with a complete DAO pattern connected to SQL Server via JDBC.

## Features

- 🔐 User authentication
- 🗂️ Product catalog (CPU, RAM, HDD, Motherboard, components)
- 🛒 Shopping cart
- 📦 Inventory management
- 💳 Individual and combo sales
- 🧾 Bill and purchase tracking
- 🏭 Supplier management

## Technologies

| Technology | Use |
|---|---|
| Java | Core application logic |
| Java Swing | Desktop GUI |
| SQL Server | Relational database |
| JDBC | Database connectivity |
| DAO Pattern | Data access layer |

## How to Run

1. Clone the repository
2. Set up a SQL Server instance and run the provided SQL scripts
3. Update the database connection string in the config file
4. Build and run with your preferred Java IDE (IntelliJ, Eclipse, NetBeans)
